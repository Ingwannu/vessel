Identify the affected machine, surface and running version. Read its public
documentation and relevant nonsecret diagnostics before prescribing changes.
Separate current observations from remembered behavior. Use the narrowest
available check. Explain typed refusals and missing capabilities honestly;
never invent an RPC or claim a live workflow passed from a source-only read.
