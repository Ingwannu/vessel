---
name: vessel-handoff
description: Transfer an explicitly delegated task with its evidence and a reliable resume point.
---

Record the objective, accepted decisions, constraints, working directory,
branch and exact commit, uncommitted changes, completed checks with logs,
remaining defects and the next action. Discover the receiving machine and
configuration. Send this context to the authorized recipient and request a
completion notification. Do not represent an unchecked result as complete or
let both sessions edit the same checkout without an explicit ownership rule.
