name: vessel
description: Coordinate agent sessions and their work through Vessel's node tools.
---

Use the Vessel tools available in this session. Discover machines before
choosing a destination and keep the destination with every session ID.
Read the available harnesses, profiles and harness options before choosing a
provider configuration. Account profiles are not named task instructions.

Create a worktree first when work needs a separate checkout. Sessions you
create are yours to drive; an existing session's presence in a list does not
grant authority to change it. Follow the destination's typed refusal.

Request completion notifications when delegating. Continue independent work
and finish your turn when waiting for a worker's notification. Read current
conversation state when answering a permission request; do not replay an old
request from the log as if it were still pending. Do not start schedules or
heartbeats unless the user requested recurring work.
