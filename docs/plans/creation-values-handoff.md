# Creation value leaf

This native view-only producer carries the exact creation value/rule/test
blobs from immutable 19e1cacc3. It includes DraftSeed, WorkspaceForm and the
NewWorkspaceSeed alias, launch distinctions, bounded shell input, local Ticket
and route-safe Flow. No editor, route, RPC, file pipeline or node authority is
installed by this leaf.

Prerequisites are the canonical WorkspaceId identity, the previously reviewed
pure terminal-profile values, and W6 canonical context value types. Existing
consumers on 0e4 already carry those values. Adopt only this leaf while keeping
those owners' code; do not merge its temporary parent branch.

The source is copied from one immutable git object set, not regenerated or
redesigned. A separate native-view creation test run names that exact source
commit; record its actual disposition, never infer app/seed runtime readiness
from a value test. The scoped editor/seed pipeline remains a separate packet.
