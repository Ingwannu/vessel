# Captured timeline row carrier

This preparation extends the existing row/toggle renderer on announced base10.
It contains the accepted staged resident predicates and W4's exact clean A8
companion12b12d4e. No moving A7/A8 branch, root value, wire, Kit or new registry is
introduced. Current product main remains the legacy selected session.

[Decision Log]
- Purpose: lazy resident bodies must carry the exact admitted context into every
  retained row processor and reusable disclosure callback.
- Existing assets/constraint: the old Copy Seat held two raw function pointers;
  row closures also hardcoded the window-global origin. A8 owns its field and
  response mechanics. W12 owns the sole resource map and actual product cutover.
- Alternatives: swapping selected globals, copying controllers, or resolving the
  current alias at dispatch would bypass original context and stale-row fencing.
- Choice: one Clone Seat enum with an explicit Legacy function-pointer variant,
  a captured parent Origin and a literal test-only admitted variant. Admitted
  getters reuse checked252 predicates; cheap Arc clones retain the same context.
  Each origin call derives one level from its captured parent. The explicit old
  ORIGIN constant remains only for unconverted legacy compatibility.
- Why: getters return borrows tied only to Shell, so temporary Place::SEAT consts
  remain valid. A missing scoped resource returns None, never a legacy fallback.
  Parent row measurement uses that same carrier after an origin toggle.
- Effects: existing product callbacks use the Clone mechanics, with unchanged
  legacy ownership. Admitted construction, registry/factory/storage/follow and
  global removal remain staged until W12's single coordinated product union.

A7 owns Seat declarations/export and the existing rows, Paint, entry callbacks,
toggle processors and origin measurement. W4 owns permission/question/dock,
response handlers and Place::answer/tool mechanics; its companion is consumed as
an exact independent producer. The new populated fixture uses the actual row
carrier and Shell toggle function across deep origins and stale presentation;
it is not a keyboard, pointer, IME, authority or live multi-pane UI proof.

Status: source preparation only. Strict App checks and the concrete tests have
not executed. No staging attribute has been removed and no product resource has
