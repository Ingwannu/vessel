# Shared client-book values producer

Scope: additive root-only values on announced package base6, no Settings
consumer, private-file staging, new rustix dependency, connector or store.
The earlier E2 branch hosts module was never on base6, so cherry-picking
its deletion/re-export move would be a misleading integration patch.
This producer adds the same root blobs independently. E1 keeps the old
native paths and all7 consumer tests on its consuming branch.

BookRouteId is nonzero u32, entry-scoped/client-minted, not a connection
lifetime or wire field. Checked next exposes exhaustion. Three drafted
tests cover zero/bounds/one-over, exact TOML and JSON/JavaScript numbers.
Label/EmptyLabel, Color11 and BadgePreference are the exact root source
from ccedd4860 (V3 SOURCE passed/gate owed). Three producer tests preserve
catalogue/defaults, full JS whitespace/Unicode/serde and typed fallback.
No label truncation or4096-byte file edge is implemented here.

Direct rustfmt/size/whitespace are source checks only. Root Clippy/tests
and E1 native re-export consumers still require actual remote execution.
Do not hand this to the integrator/B0 as ready before those receipts and
V3 bounded shared-producer review. Earlier private-file and field source,
runtime, permissions and full E1/F5 parity are excluded.
