## Query admission decision

[Decision Log]
- Purpose: preserve one PTY response authority when both node capture and
  native views interpret the same terminal.
- Existing assets: vt100's `Callbacks` already receives decoded unhandled
  CSI/OSC; the server's handlers define the response whitelist.
- Alternatives: another byte recognizer, viewer responses, or reuse decoded
  callbacks. A second recognizer duplicates parsing; viewer responses race.
- Choice: modify the facade with a typed construction-time `ReplyDuty` and
  bounded ordered `Replies` in each feed. Ordinary construction stays silent.
- Why: reuses the only interpreter and leaves I/O/ordering with the actor.
- Impact: fixed server colors replace the old proposed theme-color policy;
  observers never answer. Query sink admission errors are explicit.

The query oracle was generated by executing the exact server handlers
and factory, with source/extraction hashes retained beside the evidence.
Tests cover whole/split bytes, pending wrap, region/origin, alternate screen,
OSC whitespace, unsupported/clipboard requests and bounded bursts. No PTY
or UI behavior is claimed. New source checks are owed after the immutable
reflow candidate finishes its already registered remote run.
