# Shared syntax producer (F5 portable source)

This exports the sole source palette/role table, existing editor resolver,
and unchanged seven-arm lexer-to-kit bridge from F5. It contains no new
lexer, field, font, theme tile, readonly preview or preference. CodeStyles
resolves the selected syntax palette for a supplied light/dark Scheme;
set_syntax_palette refreshes existing windows, without editing state.

Source is pinned in the external packet manifest. This portable assembly
is UNVERIFIED until the F5 producer check is reported; a checked larger
source never substitutes for the consumer union check. Preserve any newer
CodeEditor and line_syntax owner changes when applying the bounded delta.
No standalone whole gate, UI, physical GPU or package approval is claimed.
