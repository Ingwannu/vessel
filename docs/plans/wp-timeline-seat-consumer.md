# Clone row carrier in the complete A7 renderer

This isolated consumer combines A7 source on the announced base13 with the exact
minimal row producer f264918c and W4's exact12b/cfe companion. Those preparations
remain unreviewed/unexecuted at assembly time. This is not a line handoff.

[Decision Log]
- Purpose: full A7 adds compact tool sheets and whole-turn controls beyond the
  baseline row producer; these callbacks must retain the same captured Seat.
- Existing assets and constraints: the one Clone Seat delegates the checked
  staged ResidentSeat predicates. W4 owns permission/question response mechanics.
  W12 owns actual product resource admission, storage, lazy body and follow.
- Alternatives: retaining Copy globals for the new callbacks or resolving a
  failed scoped lookup through the selected session would lose source identity.
- Choice: consume the exact W4 companion and extend only A7 row/tool-sheet/turn
  callbacks. Each retained closure owns a cheap Clone and borrows it per dispatch.
  List rows and compact overlay retain separate handles to the same carrier.
  Origins derive their original parent; list invalidation uses that same parent.
- Why: one enum and one get/get_mut contract fences every converted callback,
  without a second map, alias-based fallback or copying live controllers.
- Effects: admitted construction/resources remain literal cfg(test). The current
  product session remains explicit Legacy. The old act_at transport accepts only
  legacy_target and refuses admitted/origin carriers even with shown state.
  Actual guarded network actions and all-owner cutover remain W12's atomic union.

W4 private response integration is not imported or reproduced here. The full
A7 consumer needs its own strict and meaningful callback tests after the minimal
producer checks; neither prior main tests nor producer-only tests prove this
assembled source. No live resident, focus/IME, authority or UI claim is made.
