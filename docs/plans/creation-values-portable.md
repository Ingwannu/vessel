# Creation values for shared consumers

This value-only producer is based on package base8 plus canonical composer
context values20ea88e2436029b2b9c514dab06a3f554792538d. A consumer already
carrying that context module needs only this leaf; it introduces no App,
link, node runtime, receipt store, wire row or protocol assignment.

The terminal-profile module is byte-identical to reviewed5c39da5f: six pure
tests and strict proto Clippy passed there, with V3 source acceptance. The
view creation module is byte-identical to19e1cacc3 and checked309f0cc67:
the exact former executed fifteen creation tests without failures; the latter
passed all-target App/View/Link/Kit Clippy. These are source-equivalent prior
checks, not a fresh isolated build of this new merge base.

Consumers get Ticket/Flow and stage-specific uncertainty, literal terminal
launch planning, bounded shell input including CR, DraftSeed, SeedPlace,
DraftDestination, ProjectSeed, WorkspaceForm/NewWorkspaceSeed and SeedProblem.
ExistingWorkspace always carries the canonical WorkspaceId; no cwd, legacy
session or global New alias can replace it. Payload history uses the one
canonical ChatHistory type. The default profile list is pure data, not a
claim that a program is installed or allowed to launch.

The choice reuses the existing typed context and UUID owners; no external
library or second draft identity is introduced. Public values make producer
coordination possible without importing the moving creation/composer App
stack. Actual seed intake, live layout ownership, root/config authority and
resource creation require their separately checked consumers. No runtime or
whole-package acceptance is claimed by this cut.
