This is a source-only receiving preparation on the official base13 common input
packet. It carries only B1-owned corrections reviewed at the source checkpoint
for V4 row290. It does not inherit the frozen candidate's root, image-codec
fixtures, foreign A1/C5 branches, or its earlier gate and capture receipts.

[Decision Log]
- Purpose: prevent old rendered indices acting on newer suggestion/attachment
  data within the same draft, connection and root.
- Existing assets: the current typed request/token, attachment tray, immutable
  context entries, kit callback constructors and bounded viewer remain canonical.
- Alternatives: synchronization on repaint or matching values alone cannot
  distinguish a removed and recreated identical attachment.
- Choice: capture request plus actual row; opaque file incarnation; context
  incarnation plus source revision. Resolve these exact identities on delivery.
- Impact: no second registry or I/O authority. Stale actions are refused, while
  upload progress retains its resource identity. The kit/B2 input, fullscreen,
  paste, workspace-card and W3 getter integrations are preserved.
