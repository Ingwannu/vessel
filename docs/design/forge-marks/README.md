Retrieved 2026-11-20 for "Open on <forge>" (TRACKER 467 step B, ADR 0123

Paseo draws a forge in its open-in-editor list as the forge's brand icon in
the muted text colour (`packages/app/src/workspace/open-in-editor/button.tsx:56`,
pinned 0.15.4). Vessel never copies or traces Paseo's artwork: each mark
below is Simple Icons' path, drawn in one colour, the text colour of the
control it sits in, so it follows every theme. The page embeds the paths
(`web/src/ui/kit/forge-marks.ts`, held to these files by
`forge-marks.test.ts`); the native app reads these files.
