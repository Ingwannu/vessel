# Slice A: agent lifecycle (Paseo 0.15.4)

Source root: `~/refs/paseo-latest/packages`. Short names: S = `server/src/server`, A = `app/src`, C = `client/src`, P = `protocol/src`, CLI = `cli/src`.
Overview: an agent is one record in `AgentStorage` (JSON per agent under `<paseoHome>/agents/<project-dir>/<id>.json`) plus, while loaded, a `ManagedAgent` in `AgentManager` (S/agent/agent-manager.ts) that owns a provider `AgentSession`. Lifecycle states: `initializing | idle | running | error | closed` (P/agent-lifecycle.ts `AGENT_LIFECYCLE_STATUSES`). "closed" = no live runtime (stored only).

## Agent data model and storage (agent-storage, agent-projections, agent-owner)
- **Stored record** `STORED_AGENT_SCHEMA` (S/agent/agent-storage.ts:57-85, zod): `id, provider, cwd, workspaceId?, createdAt, updatedAt, lastActivityAt?, lastUserMessageAt?, title?, labels (default {}), lastStatus (default "closed"), resumeOnStartup?, lastModeId?, config (SerializableAgentConfig: modeId, model, thinkingOptionId, featureValues, providerOptions, toolPolicy{preapproved:[{kind:"mcp",server,tool}]}, systemPrompt, mcpServers), launchEnv?, runtimeInfo?{provider,sessionId,model,thinkingOptionId,modeId,extra}, features?, persistence?{provider,sessionId,nativeHandle?,metadata?}, lastError?, requiresAttention?, attentionReason? ("finished"|"error"|"permission"), attentionTimestamp?, internal?, archivedAt?, owner?`.
- **Files**: `AgentStorage(baseDir)`, `baseDir = <paseoHome>/agents` (S/config.ts:635 `agentStoragePath`; constructed S/bootstrap.ts:940). Path = `baseDir/<projectDirNameFromCwd(cwd)>/<id>.json` (agent-storage.ts:437-445: strips drive/UNC root, joins path segments with `-`). Root-level `*.json` and one-level project dirs are scanned on load (`scanDisk`). Invalid files are logged and skipped. If `cwd` changes the file moves (old path unlinked).
- **Write model**: per-agent promise queue (`pendingWrites`), atomic write `writeJsonFileAtomic` (S/atomic-file.ts), in-memory cache `Map<id, record>`; `remove(id)` first sets a `deleting` fence so queued writes are dropped, then unlinks all indexed paths. `flush()` awaits all queued writes. `applySnapshot(agent, {title?, internal?})` projects a live agent via `toStoredAgentRecord` and keeps existing title/createdAt/`archivedAt`; sets `resumeOnStartup = existing.resumeOnStartup && lifecycle not idle/error`. `setTitle`, `listByProviderSession(provider, handleId)` (matches `sessionId` or `nativeHandle`), `listByWorkspace`, `findByDaemonExecution(owner)`.
- **Persistence trigger**: `attachAgentStoragePersistence` (S/persistence-hooks.ts:45) subscribes to `agent_state` events and `applySnapshot`s every non-"closed" state; AgentManager also persists explicitly (`persistSnapshot`, `enqueueBackgroundPersist`). Internal agents are never persisted.
- **Migration**: only one, `backfillWorkspaceIdForLegacyAgents` (S/migrations/backfill-workspace-id.migration.ts, "COMPAT(workspaceIdBackfill)", delete after 2026-12-16): stamps `workspaceId` on records without one, picking exact-cwd workspace (oldest wins) else deepest enclosing workspace dir, never the home dir; archived records may resolve to archived workspaces. No schema-version field exists; zod defaults handle older files. Not found: any sqlite agent table (looked in S/agent, S/migrations; agents are JSON only).
- **Owner** (S/agent/agent-owner.ts): `AgentOwnerSchema = {kind:"daemon", daemonId, executionId}`; `daemonExecutionKey = daemonId + "\0" + executionId`; storage indexes it for hub executions. Records with an owner are excluded from restart recovery.
- **Projections** (S/agent/agent-projections.ts): `toStoredAgentRecord(agent)`, `toAgentPayload(agent, {title, archivedAt})` -> `AgentSnapshotPayload` (live), `buildStoredAgentPayload(record, validProviders)` -> same shape for unloaded agents (default capabilities, `availableModes: []`, `pendingPermissions: []`, `providerUnavailable: true` when provider not registered), `toAgentListItemPayload` -> `AgentListItemPayload {id, shortId (id.slice(0,7)), title, provider, model, thinkingOptionId, effectiveThinkingOptionId, status, cwd, createdAt, updatedAt, lastUserMessageAt, archivedAt, requiresAttention, attentionReason, attentionTimestamp, labels, providerUnavailable?}`, `selectAgentListItems({cwd, statuses, sinceHours (default 48), limit (default 50)})` (sort: requiresAttention first, then status order running<initializing<idle<error<closed, then newest activity; archived agents shown only if active within `sinceHours`), `toRecentProviderSessionDescriptorPayload`. `resolveStoredAgentUpdatedAt(record)` = max(updatedAt, lastActivityAt) (persistence-hooks.ts:107; reason: rename/label/unarchive/mark-unread move only `updatedAt`).
- **Wire payload** `AgentSnapshotPayloadSchema` (P/messages.ts:863): `id, provider, cwd, workspaceId?, model, features?, thinkingOptionId?, effectiveThinkingOptionId?, createdAt, updatedAt, lastUserMessageAt, status, activeTurn?{turnId,startedAt}, capabilities, currentModeId, availableModes, pendingPermissions, persistence, runtimeInfo?, lastUsage?, lastError?, title, labels, requiresAttention?, attentionReason?, attentionTimestamp?, archivedAt?, providerUnavailable?, internal?`. Persistence `metadata.mcpServers` is stripped for the wire (`projectPersistenceHandleForWire`).
- Connections: timeline (S/agent/agent-timeline-store, other slice), provider registry (`isStoredAgentProviderAvailable`), workspace registry (workspaceId), hub executions (owner).

## Agent state buckets and lifecycle statuses (agent-state-bucket, agent-lifecycle)
- `deriveAgentStateBucket` (P/agent-state-bucket.ts): `needs_input` if pendingPermissionCount>0 or attentionReason=="permission"; `failed` if status=="error" or attentionReason=="error"; `running` if status=="running"; `attention` if requiresAttention; else `done`. `WorkspaceStateBucket` = `needs_input|failed|running|attention|done` (zod enum P/messages.ts:1331). `getAgentStatusPriority`: permission 0, error 1, running 2, initializing 3, else 4 (server sort key `status_priority`, `agentsPager` in S/session.ts).
- App: `A/utils/sidebar-agent-state.ts`: `deriveSidebarStateBucket`, `isSidebarActiveAgent` (bucket != done), `aggregateSidebarStateBuckets` (collapsed project row priority needs_input>failed>running>attention>done), `STATUS_BUCKET_ORDER` (side-by-side order needs_input, failed, attention, running, done). `A/contexts/session-status-tracking.ts` `reconcilePreviousAgentStatuses` keeps a per-session previous-status map.
- Server transitions: `AgentManager.registerSession` ends with `lifecycle="idle"`; turn start -> `running`; `onStreamTurnCompleted` -> idle; `turn_failed` -> `error` (+ `lastError`, a "[System Error]" timeline row); `closed` only via `prepareAgentForClosure`/`emitClosedAgent`. Attention is edge-triggered in `checkAndSetAttention` (agent-manager.ts:5214), see "Attention".

## Archive / unarchive / close (agent-archive, close_items)
- **Wire**: `archive_agent_request {agentId, requestId}` -> `agent_archived {agentId, archivedAt, requestId}`; `close_items_request {agentIds[], terminalIds[], requestId}` -> `close_items_response` (agents archived in parallel with `Promise.allSettled`, failures logged and omitted; terminals killed). - **Command** `archiveAgentCommand` (S/agent/lifecycle-command.ts): live agent -> cancel active run (`requestAgentRunCancellation`), `clearAgentAttention`, `AgentManager.archiveAgent`; stored-only -> `archiveSnapshot(id, now)`; already archived returns existing record. Session `archiveAgentForClose` (session.ts:3414) then pushes a stored-record `agent_update` and a workspace update.
- **AgentManager.archiveAgentUnlocked** (agent-manager.ts:2000): internal agents are not stored (final snapshot kept in memory 10 min: `RETIRED_INTERNAL_AGENT_TTL_MS = 10*60*1000`, `RETIRED_INTERNAL_AGENT_LIMIT = 500`). Internal children always archive.
- **Unarchive**: `unarchiveSnapshot(id, {workspaceId?, labels?})` (closes live runtime, `syncNativeArchiveState "restore"`, sets `archivedAt:null`); via `unarchiveAgentState` (agent-prompt.ts:~210) used by send prompt, resume, refresh (`refresh_agent_request`), import. - **App archive**: `useArchiveAgent` (A/hooks/use-archive-agent.ts) optimistic mutation: marks pending key `serverId:agentId` in react-query `["archive-agent-pending"]`, removes the agent from caches `["sidebarAgentsList", serverId]`, `["allAgents", serverId]`, marks history caches (`agentHistoryQueryKey`) archived, restores snapshots on failure. - Schedules: scheduled runs create/resume agents.
- CLI/client/relay: all requests go through `DaemonClient` (WebSocket or relay E2EE); features negotiated via `status.server_info.features` (`creationLifecycle`, `agentRequestReceipts`, `workspaceRequestReceipts`, `agentForkContext`, `idleRuntimeCleanupSetting`, `resumeOnStartupSetting`, `workspaceMultiplicity`, `forgeSearch`, `wholeTurnTimeline`).
