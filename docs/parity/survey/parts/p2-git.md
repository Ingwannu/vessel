# p2-git: Git panel, checkout, diff (Paseo 0.15.4, packages/*/src)

Conventions: P = packages/protocol/src/messages.ts, S = packages/server/src, SS = S/server, A = packages/app/src. Every request carries `requestId: string`; every response payload echoes `requestId` and `cwd`. Errors on the wire are `CheckoutError = { code: "NOT_GIT_REPO"|"NOT_ALLOWED"|"MERGE_CONFLICT"|"UNKNOWN", message }` (P:2243-2253); server maps via `toCheckoutError` (SS/checkout-git-utils.ts:41: NotGitRepoError->NOT_GIT_REPO, MergeConflictError and MergeFromBaseConflictError->MERGE_CONFLICT, other Error->UNKNOWN; NOT_ALLOWED is declared but never produced here). All checkout_* RPCs are dispatched by `Session.dispatchCheckoutMessage` (SS/session.ts:2991-3055) into `CheckoutSession` (SS/session/checkout/checkout-session.ts). There is NO stage/unstage/file-level-stage protocol message and no UI for it (not found: grep "stage" in protocol messages.ts checkout section, app/src/git); the only index touching ops are commit `addAll` (git add -A) and discard (reset then checkout/clean).

## Protocol catalogue (git/checkout part)

### Shared payload schemas
- `CheckoutDiffCompare` (P:2255): `{ mode: "uncommitted"|"base"|"all", baseRef?: string, ignoreWhitespace?: boolean }`.
- `ParsedDiffFile` (P:2797): `{ path, oldPath? (COMPAT diffOldPath, remove after 2027-02-09), isNew, isDeleted, additions, deletions, hunks: DiffHunk[], status?: "ok"|"too_large"|"binary" }`. `DiffHunk` (P:2789) `{ oldStart, oldCount, newStart, newCount, lines: DiffLine[] }`. `DiffLine` (P:2783) `{ type: "add"|"remove"|"context"|"header", content, tokens?: {text, style: string|null}[] }` (tokens = server-side syntax highlight, compound class names like "heading meta").
- `CheckoutStatus` payload (P:5387-5452), union discriminated by `isGit`/`isPaseoOwnedWorktree`; common: `cwd, error: CheckoutError|null, requestId, upstreamRef?: string|null` (full ref as git resolves `<branch>@{upstream}`, e.g. `refs/remotes/origin/main`; clients must use verbatim; aheadOfOrigin/behindOfOrigin measured vs exactly this ref).
  - NotGit: `isGit:false, isPaseoOwnedWorktree:false, repoRoot:null, currentBranch:null, isDirty:null, baseRef:null, aheadBehind:null, aheadOfOrigin:null, behindOfOrigin:null, hasRemote:boolean, remoteUrl:null`.
  - GitNonPaseo: `isGit:true, isPaseoOwnedWorktree:false, repoRoot:string, mainRepoRoot?:string|null (default null), currentBranch:string|null, isDirty:boolean, baseRef:string|null, aheadBehind:{ahead,behind}|null, aheadOfOrigin:number|null, behindOfOrigin:number|null, hasRemote:boolean, remoteUrl:string|null`.
  - GitPaseo (paseo-owned worktree): same but `isPaseoOwnedWorktree:true, mainRepoRoot:string, baseRef:string` non-null.
- `CheckoutCommit` (P:2379): `{ sha, shortSha, subject, authorName, authorDate (ISO 8601), isOnRemote: boolean (false=unpushed), isOnBase?: boolean (COMPAT commitBaseClassification, remove optional after 2027-01-23), files: {path, additions, deletions, status?: "added"|"modified"|"deleted"|"renamed"}[] }`.
- `StashEntry` (P:6008): `{ index:int>=0, message, branch:string|null, isPaseo:boolean }`.

### How checkout_status_update subscription is enabled
Client sends `session.events.set_subscription.request` with `events` including `"checkout_status_update"` (SS/session.ts:2819-2845). Server stores an event subscription, then `reconcileWorkspaceGitObservers()` (session.ts:6803) which asks `workspaceDirectory.listObservationTargets()` for ALL workspaces (not only those the client displays) and calls `WorkspaceGitObserverService.reconcileObservers`. When the owner drops, the observers reconcile again. See p-events surveyor for the generic subscription protocol.

## Server: CheckoutSession read side
- Status: `workspaceGitService.getSnapshot(expandTilde(cwd))` -> `buildCheckoutStatusPayloadFromSnapshot` (SS/checkout/status-projection.ts:15-100). Throws "Workspace git snapshot is missing required checkout status fields" if git but repoRoot/isDirty null; paseo worktree additionally requires mainRepoRoot and baseRef. Paseo worktrees emit `mainRepoRoot` as is; non-paseo emit `mainRepoRoot` (nullable).
- `buildCheckoutPrStatusPayloadFromSnapshot` + `normalizeCheckoutPrStatusPayload` (:102-166) project the forge part (forge slice, mirrors GitHub facts onto `github` for COMPAT forgeSpecific until 2027-01-17).
- Diff read/subscribe goes through `CheckoutDiffManager` (see "Server: live diff pipeline").
- Branch validate: `assertSafeGitRef` (worktree-session) then `workspaceGitService.validateBranchRef` (auxiliary cache). Kinds: local / remote-only (resolvedRef = `origin/<name>`, isRemote true) / not-found.
- Branch suggestions: `workspaceGitService.suggestBranchesForCwd` -> `listBranchSuggestions` (S/utils/checkout-git.ts:324): lists `refs/heads` + `refs/remotes/origin` sorted by committerdate, merges same names (hasLocal/hasRemote), query = substring match (lowercased, `normalizeBranchSuggestionName`), sort: prefix matches first, then newest committerDate, then localeCompare; default limit 50, clamp 1..200; `rev-list --left-right --count refs/heads/X...refs/remotes/origin/X` gives localAhead/localBehind when both exist and oids differ (0/0 when equal; omitted on error).

## Server: checkout command semantics (write side)
After every successful mutation the handler calls `gitMutation.notifyGitMutation(cwd, reason, {invalidateForge?})` (SS/session/git-mutation/git-mutation-service.ts:72) = optional `workspaceGitService.invalidateForge(cwd)` then `getSnapshot(cwd, {force:true, reason})` (failure only logged), and usually `scheduleDiffRefresh(cwd)` = `checkoutDiffManager.scheduleRefreshForCwd`. `GitMutationRefreshReason` (S/utils/checkout-git.ts:65): commit-changes, pull, push, merge-to-base, merge-from-base, merge-pr, enable-pr-auto-merge, disable-pr-auto-merge, create-pr, switch-branch, rename-branch, create-branch, stash-push, stash-pop, discard-changes, create-worktree. cwd for all commands is passed through unchanged (status/read paths use `expandTilde`, writes do not).
- **Commit** (`handleCheckoutCommitRequest` :742): `message = msg.message?.trim()`; if empty -> `gitMetadataGenerator.generateCommitMessage(cwd)` (LLM); if still empty throws "Commit message is required". `commitChanges(cwd,{message, addAll: msg.addAll ?? true})` (checkout-git.ts:3722): `requireGitRepo`, `git add -A` (timeout 120_000) if addAll, `git commit -m <message>` (120_000). Reason `commit-changes`. No amend, no staged-only commit from UI beyond addAll=false.
- **Commit message generation** (SS/session/checkout/git-metadata-generator.ts): `generateCommitMessage` builds a prompt from `getCheckoutDiff(cwd,{mode:"uncommitted",includeStructured:true})` (file list `A|D|M\tpath\t(+a -d) [status]` + patch truncated to `MAX_COMMIT_PATCH_CHARS = 120_000`) plus style from config key `commitMessage` (default "Concise, imperative mood, no trailing period."), runs an internal non-persisted agent (title "Commit generator", maxRetries 2, providers from `resolveStructuredGenerationProviders`) with zod `{message: string 1..72}`. On `StructuredAgentResponseError|StructuredAgentFallbackError` returns fallback `COMMIT_MESSAGE_FALLBACK = "Update files"` (error logged). PR text variant: `MAX_PULL_REQUEST_PATCH_CHARS = 200_000`, fallback title "Update changes" / body "Automated PR generated by Paseo." (forge slice).
- **Discard** (`discardChanges` checkout-git.ts:3740, `DISCARD_CHANGES_TIMEOUT_MS = 120_000`): all git runs with `--literal-pathspecs` at worktree root: (1) `reset -q HEAD -- <paths>` (unborn HEAD fallback: `rm --cached -r -q --ignore-unmatch`), (2) `status --porcelain=v1 -z -- <paths>` to classify each path (renames consume next NUL token; `??` -> untracked), (3) tracked: `checkout -q -- <paths>`, untracked: `clean -fd -q -- <paths>`. Empty paths = no-op. Reason `discard-changes`. Paths are NOT validated against traversal here (protocol only requires min 1).
- **Switch branch** (`GitMutationService.checkoutExistingBranch` git-mutation-service.ts:79): `assertSafeGitRef` (regex `^[A-Za-z0-9._/-]+$` + worktree safe-ref), `validateBranchRef` (not-found -> "Branch not found: X"), `ensureCleanWorkingTree` ("Working directory has uncommitted changes. Commit or stash before switching branches."; dirty read comes from snapshot `isDirty === true`), `checkoutResolvedBranch` (checkout-git.ts:495): local -> `git checkout <name>` (skips if HEAD already equals); remote-only -> `git checkout -b <name> --track origin/<name>` and response `source:"remote"`. Then `notifyGitMutation("switch-branch",{invalidateForge:true})`, `scheduleDiffRefresh`, `host.emitWorkspaceUpdateForCwd(cwd)` (immediate `workspace_update` so sidebar/header show new branch).
- **Create branch from base** (`createBranchFromBase` :88; used by worktree/auto-naming paths, not a checkout_* RPC): validates both refs, rejects existing local branch "Branch already exists: X", requires clean tree, `git checkout -b <new> --no-track <base>` (--no-track so push never lands on the default branch).
- **Rename branch** (`handleCheckoutRenameBranchRequest` :596): `validateBranchSlug(branch)` from protocol/branch-slug first (invalid -> success false, `UNKNOWN` error with validation message, currentBranch null); then `host.renameCurrentBranch` = `renameCurrentBranch` (checkout-git.ts:1232: detached HEAD -> "Cannot rename branch in detached HEAD state"; `git branch -m <new>` timeout 120_000; then `rebindPaseoWorktreeChangeRequestHint`). Then notify `rename-branch` (invalidateForge), diff refresh, `host.handleWorkspaceGitBranchSnapshot(cwd, currentBranch)` and `emitWorkspaceUpdateForCwd`.
- **Merge to base** (`handleCheckoutMergeRequest` :785): snapshot must be git; `requireCleanTarget` + dirty -> error "Working directory has uncommitted changes."; `baseRef = msg.baseRef ?? snapshot.git.baseRef` (strip leading `origin/`), missing -> "Base branch is required for merge". `mergeToBase(cwd,{baseRef, mode: strategy==="squash"?"squash":"merge"})` (checkout-git.ts:3866): if base is checked out in another worktree, operates there (`getWorktreePathForBranch`), else checks out base in same checkout, `merge <current>` or `merge --squash` + commit `"Squash merge <cur> into <base>"`, restores original branch in a `finally` when same checkout. Conflict detection (`git diff --name-only --diff-filter=U`, `ls-files -u`, `status --porcelain` UU/AA/DD/AU/UA/UD/DU, or stderr /CONFLICT|Automatic merge failed/) -> `git merge --abort` then throws `MergeConflictError{baseRef,currentBranch,conflictFiles}` -> wire code `MERGE_CONFLICT`. Notifies the mutated cwd (`merge-to-base`, invalidateForge) and the original cwd if different.
- **Merge from base** (:846, `mergeFromBase` :3938): clean target default true (`requireCleanTarget ?? true`); picks `resolveMostAheadBaseRef` (local vs origin whichever is ahead); `git merge <best>`; conflict -> abort + `MergeFromBaseConflictError`. Reason `merge-from-base` (invalidateForge).
- **Pull** (:892, `pullCurrentBranch` :4049): requires branch (not detached "HEAD") and `origin` remote ("Remote 'origin' is not configured."); `git pull` (120_000); on failure `abortGitPullConflictState` (merge --abort / rebase --abort when MERGE_HEAD/rebase-merge/rebase-apply exist) then rethrow. Reason `pull` (invalidateForge), diff refresh.
- **Push** (:924, `pushCurrentBranch` :4068) target resolution order: (1) `branch.<b>.pushRemote` + `remote.<r>.push` refspec of form `HEAD:refs/heads/<x>` -> `git push <remote> HEAD:refs/heads/<x>` then update tracking ref / set branch.remote+merge if unset; (2) upstream `branch.<b>.remote`+`.merge` -> `git push -u <remote> HEAD:refs/heads/<head>`; (3) origin: `git push -u origin <branch>`. All timeout 120_000. Reason `push` (invalidateForge). Does NOT schedule a diff refresh.
- **Stash** (:672-740): save = `git stash push --include-untracked -m "paseo-auto-stash: <branch>"` (label `unnamed` when branch missing/blank; `PASEO_STASH_PREFIX = "paseo-auto-stash:"`), timeout 120_000, reason `stash-push`; pop = `git stash pop stash@{<index>}` (120_000) reason `stash-pop`; list = `workspaceGitService.listStashes(cwd,{paseoOnly})` parsing `git stash list` lines `ref\0subject` (SS/workspace-git-service.ts:3861): index from `{N}`, `isPaseo` = subject contains the prefix, `branch` = text after prefix or null; `paseoOnly = msg.paseoOnly !== false`.
- **Commits list** (`listCheckoutCommits` checkout-git.ts:2616): current branch required (detached -> `{baseRef:null, commits:[]}`); base ref from stored worktree base or resolved default, must differ from current branch (falls back to `resolveBaseRef`); `workspaceRecords` = `git log <base>..HEAD`, then `CHECKOUT_BASE_COMMIT_LIMIT = 10` commits from the merge-base (so the list = branch commits (isOnBase=false) followed by 10 base-history commits (isOnBase=true)); no base -> only HEAD history limited to 10. Log format `COMMIT_LOG_FORMAT = "%x1e%H%x00%h%x00%an%x00%aI%x00%s"`; per-file status/numstat from `--raw`/`--numstat` (A/C->added, M/T->modified, D->deleted, R->renamed). `isOnRemote = !unpushedShas.has(sha)`.
- **Commit file diff** (`getCommitFileDiff` :2750): request validates `assertSafeGitRef(sha,"commit")` and path not empty/absolute/containing `..`; `git show <sha> --format= --diff-merges=first-parent -M --no-ext-diff --no-color --src-prefix=a/ --dst-prefix=b/ -- :(literal)<path>[old path]` (renames discovered by `readCommitRenames`, cache `commitRenamesCache` TTL 60_000 max 100 keyed by full 40/64-hex sha only); parsed/highlighted by the same `parseAndHighlightDiff` (S/server/utils/diff-highlighter.ts:477) with old/new content read at `<sha>^` / `<sha>`; returns null when absent or binary-only.

## Server: live diff pipeline (SS/checkout-diff-manager.ts, SS/checkout-diff-cache.ts)
- `CheckoutDiffManager.read(params)` = one-shot compute (no listener). `subscribe(params, listener)` returns `{initial, unsubscribe}`.
- Targets keyed by `JSON.stringify([cwd, mode, mode!=="uncommitted"? baseRef??"" : "", ignoreWhitespace])`; `normalizeCompare` trims baseRef, forces `ignoreWhitespace` boolean; uncommitted drops baseRef. All subscriptions with the same key share one target, one watcher and one fingerprint (`JSON.stringify(payload)`); listeners only fire when the fingerprint changes.
- `CHECKOUT_DIFF_WATCH_DEBOUNCE_MS = 150`; refreshes serialize (`refreshPromise`, `refreshQueued`, `refreshQueuedForce`).
- Snapshot compute: `workspaceGitService.getCheckoutDiff(diffCwd,{mode,baseRef,ignoreWhitespace,includeStructured:true}, force?{force:true,reason})`; result `diffTooLarge` -> payload `{cwd, files:[], diffTooLarge:true, error: UNKNOWN "Diff too large to display"}`; otherwise files sorted by `path` (code-unit order), `error:null`; any exception -> `{files:[], error: toCheckoutError}`.
- Watching (`openTarget`): `mode!=="uncommitted"` ("base","all") first gets the workspace snapshot, sets `diffCwd = repoRoot`, remembers structure/worktree/forge fingerprints and `registerWorkspace` so structural changes (branch, remoteUrl, baseRef, aheadBehind, hasRemote ...) trigger an unforced refresh (`scheduleTargetRefresh(target,false)`); refreshes also fire when neither worktree nor forge changed. `mode==="base"` returns there (no working-tree watch: base..HEAD only changes with refs); `uncommitted` and `all` additionally `requestWorkingTreeWatch(cwd, onChange)` -> every file event schedules a forced refresh (reason "working-tree-watch").
- `scheduleRefreshForCwd(cwd)` refreshes targets whose cwd or diffCwd equals it (used after mutations).
- Metrics `getMetrics()`: checkoutDiffTargetCount, checkoutDiffSubscriptionCount, watcher/fallback counts hard-coded 0.
- Cache (`CheckoutDiffCache`): LRU max 64 entries keyed `[cwd, mode, baseRef|null, ignoreWhitespace, includeStructured]`; a cached value is reused when `now - loadedAt <= 15_000` ms OR `now - lastReadStarted < 2_000` ms; forced reads need a `reason` ("WorkspaceGitService forced read requires a reason"); a force during an in-flight load marks it invalidated + aborts its AbortController and deletes the entry; invalidated results are never cached; later callers wait for the old promise then re-read. `invalidate(cwd, mode)` drops entries whose cwd matches and whose mode equals `mode` or "all"(cached mode). `WorkspaceGitServiceImpl.getCheckoutDiff` (SS/workspace-git-service.ts:812) awaits the workspace's `observationSetupPromise` first, normalizes options and loads via `getCheckoutDiff(cwd, opts, {paseoHome, worktreesRoot}, signal)`. Working-tree changes call `invalidateCheckoutDiffCache(alias,"uncommitted")` for each alias (:2098).
- Diff computation (`getCheckoutDiff` S/utils/checkout-git.ts:3580): uses worktree root; refs: uncommitted = `HEAD` + untracked; base = merge-base(bestBase, HEAD) -> HEAD; all = merge-base -> working tree incl. untracked (via a private temp `GIT_INDEX_FILE` in `paseo-all-changes-*` so base-tracked-but-untracked-locally paths show). Unborn HEAD falls back to the empty tree `4b825dc642cb6eb9a060e54bf8d69288fbee4904`. Files sorted by path. Constants: `PER_FILE_DIFF_MAX_BYTES = 1 MiB` (file becomes `status:"too_large"` placeholder, no hunks), `TOTAL_DIFF_MAX_BYTES = 2 MiB` (raw `diff` text cap), `TRACKED_DIFF_NUMSTAT_MAX_BYTES = 2 MiB`, `TRACKED_DIFF_BATCH_SIZE = 64` paths per git call, `UNTRACKED_BINARY_SNIFF_BYTES = 16 KiB` (binary detection of untracked files -> `status:"binary"`), `CHECKOUT_DIFF_MAX_STRUCTURED_BYTES = maxSecuredPlaintextByteLength(MAX_RELAY_WEBSOCKET_MESSAGE_BYTES) - 1 MiB` (relay 32 MiB frame limit; exceeding it -> whole result `{diff:"", structured:[], diffTooLarge:true}`). Git args `GIT_PATCH_FORMAT_ARGS = --no-ext-diff --no-color --src-prefix=a/ --dst-prefix=b/`; `ignoreWhitespace` adds the git whitespace-ignore flags via `buildGitDiffArgs`.

## Server: WorkspaceGitService (SS/workspace-git-service.ts, ~3986 lines) and observation
Role: single owner of per-cwd git runtime snapshots, watchers, caches, background fetch and forge polling; `CheckoutSession`, `CheckoutDiffManager`, the workspace descriptor builder and the session-level observer all read through it.
- `WorkspaceGitRuntimeSnapshot` (:151): `{cwd, git:{isGit, repoRoot, mainRepoRoot, currentBranch, remoteUrl, isPaseoOwnedWorktree, isDirty, baseRef, aheadBehind, upstreamRef, aheadOfOrigin, behindOfOrigin, hasRemote, diffStat:{additions,deletions}|null}, forge:{featuresEnabled, authState, forge?, pullRequest|null, error}}`. Git half is produced by `getCheckoutStatus`, `getCheckoutShortstat` (diffStat; cache TTL 15_000, max 1_000, `UNTRACKED_SHORTSTAT_MAX_FILES = 500`), `getCheckoutRefDerivedState` (narrow refresh after remote ref moves), `getCheckoutWorktreeState` (isDirty+diffStat only).
- Public interface (:200): registerWorkspace({cwd}, listener) -> {unsubscribe}; onSnapshotUpdated; getCheckout (lite project payload); getSnapshot(cwd, {force?, includeForge?, reason}) (force requires reason: "WorkspaceGitService.getSnapshot force refresh requires a reason"); resolveForge; getCheckoutDiff; validateBranchRef; hasLocalBranch; suggestBranchesForCwd; listStashes; listWorktrees/invalidateWorktrees; getProjectSlug; resolveRepoRoot; resolveDefaultBranch; resolveRepoRemoteUrl; refresh(cwd); requestWorkingTreeWatch(cwd,onChange)->{repoRoot,unsubscribe}; scheduleRefreshForCwd; onWorkspaceStateMayHaveChanged (invalidate forge + forced refresh incl. forge reason "external-state-change"); invalidateForge; getMetrics; dispose.
- Refresh pipeline: `scheduleWorkspaceRefresh` debounces by `WORKSPACE_GIT_WATCH_DEBOUNCE_MS = 1_000` merging requests (`WorkspaceGitRefreshRequest` {force, refreshStructure, refreshWorktree, includeForge, emitUnchanged?, reason, queueIfBusy, movedRemoteRefs}); scope `worktree` = only isDirty/diffStat, `structure`, `refs`; `requestWorkspaceSnapshot` coalesces in-flight work and queues only if it adds work; non-forced, non-queued reads within `WORKSPACE_GIT_INTERNAL_MIN_GAP_MS = 2_000` of the last shell-out return the cached snapshot; concurrency `WORKSPACE_GIT_REFRESH_CONCURRENCY = 4`, observation setup `WORKSPACE_GIT_OBSERVATION_SETUP_CONCURRENCY = 2`. Snapshot is emitted to `target.listeners` and `snapshotUpdatedListeners` only when `JSON.stringify(snapshot)` differs (or `forceEmit`).
- Auxiliary reads (`readAuxiliaryCache`): LRU max `WORKSPACE_GIT_AUXILIARY_CACHE_MAX = 256` per cache (branchValidation, localBranch, branchSuggestions, stashList, worktreeList, defaultBranch); fresh within `WORKSPACE_GIT_AUXILIARY_READ_TTL_MS = 15_000`, stale reads suppressed within the 2 s min gap, in-flight dedupe; `force` needs `reason`.
- Observation setup (`setupWorkspaceObservation` :1283): load snapshot facts; ensure a shared working-tree watch target for the worktree root (`ensureWorkingTreeWatchTarget`, file observer subscription with ignore list of gitignored directories from `git ls-files -o -i --directory --exclude-standard`, refresh quiet `WORKING_TREE_IGNORE_REFRESH_QUIET_MS = 300`, max delay `..._MAX_DELAY_MS = 2_000`, known-dir cap `WORKING_TREE_KNOWN_DIRECTORIES_MAX = 50_000`); ensure a shared repo-metadata target keyed by common git dir (`ensureRepoTarget` :2148) that watches `.git` with the rule table in `SS/git-metadata-event-rules.ts` and triggers the background fetch timer. Watcher subscribe deadline `WORKSPACE_GIT_WATCHER_SUBSCRIBE_TIMEOUT_MS = 10_000`. Re-ensure timer every `WORKSPACE_GIT_OBSERVATION_REENSURE_INTERVAL_MS = 60_000` (phase per cwd via `getWorkspaceGitObservationReensurePhaseMs`).
- Working-tree event path: any change -> `notifyWorkingTreeChanged`: invalidate diff cache for each alias (mode "uncommitted"), call every `requestWorkingTreeWatch` listener (the diff manager), and schedule a `worktree`-scope refresh of linked workspace targets.

- `GitActionId`: commit, pull, push, pull-and-push, pr, merge-pr-squash|merge|rebase, enable-pr-auto-merge-squash|merge|rebase, disable-pr-auto-merge, merge-branch, merge-from-base, archive-workspace. `GitAction = {id,label,pendingLabel,successLabel,disabled,status("idle"|"pending"|"success"),unavailableMessage?,icon?,startsGroup,handler}`.
- Not git -> all empty. Inputs come from `useGitActions` (status, PR status, store statuses): isGit, hasRemote, isPaseoOwnedWorktree, isOnBaseBranch (`currentBranch === baseRefLabel`, label strips `refs/heads|remotes/` and `origin/`), hasUncommittedChanges (`status.isDirty`), baseRefAvailable, aheadCount (`aheadBehind.ahead` = commits ahead of base), behindBaseCount (`aheadBehind.behind`), aheadOfOrigin/behindOfOrigin, shouldPromoteArchive, shipDefault ("pr"|"merge"), PR facts + `mergeCapability`.
- PRIMARY selection order (`getPrimaryActionId`): 1 archive if `shouldPromoteArchive` (= !dirty && (postShipArchiveSuggested || PR merged)); 2 commit if dirty; 3 pull if `canPull` (hasRemote && !dirty && behindOfOrigin>0); 4 push if `canPush` (hasRemote && hasPushableCommits && behindOfOrigin===0; pushable = aheadOfOrigin>0 OR (Paseo worktree with aheadOfOrigin===null && aheadCount>0)); 5 direct PR merge (preferred method) if `canMergePr`; 6 enable auto-merge if `canEnablePrAutoMerge`; 7 `pr` (view) if auto-merge already enabled; 8 `pr` if shipDefault==="pr" && forge features && (has PR with url, or aheadCount>0 and not on base); 9 merge-branch if !onBase && aheadCount>0; 10 merge-from-base if !onBase && baseRef && !dirty && behindBase>0; 11 `pr` if forge enabled and PR with url exists; 12 archive-workspace only for Paseo-owned worktrees; else none.
- SECONDARY list: `pull, push, pull-and-push` always; if `!isOnBaseBranch` also `merge-from-base, merge-branch` + PR actions (`pr`, allowed direct merges, allowed auto-merge enables, `disable-pr-auto-merge` when auto-merge enabled); finally `archive-workspace` (dropped when it is already primary). The split button renders `secondary` in the caret menu; `actionsWithoutPrimary()` de-dupes for flattened lists. `startsGroup` (separator before item) true for merge-from-base, archive, first of each merge/auto-merge trio, disable-auto-merge.
- `canMergePr`: forge features && PR open && !draft && !merged && mergeable !== "CONFLICTING" && aheadCount>0 && !dirty, and then either (no capability) mergeable==="MERGEABLE" && behind/ahead of origin both 0 && !canMergeFromBase, or (capability) `directMergeReady && !autoMergeEnabled && !mergeBlockedByQueue && >=1 allowed method`. `MergeCapability` comes from `deriveMergeCapability(prStatus.forgeSpecific, prStatus.github)` (A/git/merge-capability.ts) via registered `CLIENT_FORGE_LOGIC_MODULES` (forge slice).
- Disabled/unavailable: runtime `disabled = actionsDisabled(!isGit || status.error || statusLoading) || status==="pending"`. `unavailableMessage` (shown as a toast `durationMs 3200` with Info icon when pressed instead of running, `useGitActionRunner`) is computed per action: pull (no remote / dirty / behindOfOrigin null->no remote / 0->up to date), push (no remote / behind / nothing to push), pull-and-push (no remote, dirty, no incoming, in sync, nothing to push), create-PR (forge not connected, aheadCount 0), merge-branch (no base, dirty, nothing), merge-from-base (no base, dirty, behindBase 0), merge-PR variants (no forge, no PR, draft, merged, closed, conflicts, queue, not ready), disable-auto-merge (cannot disable). English copy in A/i18n/resources/en.ts:794-935 (`workspace.git.actions.*`); labels: Commit/Committing.../Committed, Pull/Pulling.../Pulled, Push/Pushing.../Pushed, "Pull and push", "Merge locally"/Merging.../Merged, "Update from {baseRef}"/Updating.../Updated, "Archive workspace", "View PR|MR", "Create PR|MR", "Merge PR (squash|merge|rebase)", "Auto merge (squash|merge|rebase)", "Auto-merge enabled". Toast failures: failedCommit/Pull/Push/PullAndPush/CreatePr/MergePr/EnableAutoMerge/DisableAutoMerge/baseRefUnavailable/failedMerge/failedMergeFromBase.
- Persisted: ship default per repo, AsyncStorage key `@paseo:changes-ship-default:<repoRoot>`, values "pr"|"merge", default "pr" (written by `persistShipDefault`).
- `postShipArchiveSuggested` local state set true after successful merge-PR / merge-branch; reset on cwd change -> promotes Archive to primary.

### Action store (A/git/actions-store.ts, zustand `useCheckoutGitActionsStore`)
- State `statusByCheckout[serverId::cwd][actionId] = "idle"|"pending"|"success"`; ids: commit, pull, push, pull-and-push, refresh, create-pr, merge-pr-<m>, enable-pr-auto-merge-<m>, disable-pr-auto-merge, merge-branch, merge-from-base, discard-changes. `SUCCESS_DISPLAY_MS = 1000` (success flashes then returns to idle). Duplicate invocations of the same (checkout, action) while in flight await the existing promise (`inFlight` map). On success `invalidateCheckoutGitQueriesForClient`. On failure status returns to idle and the error propagates (callers toast).
- Calls: commit -> `client.checkoutCommit(cwd,{addAll:true})` (NO message: server generates one via LLM, so the UI has no commit-message input, no amend, no partial staging); pull -> `checkoutPull`; push -> `checkoutPush`; pullAndPush = sequential pull then push (stops on first error); refresh -> `checkoutRefresh`; mergeBranch -> `checkoutMerge(cwd,{baseRef, strategy:"merge", requireCleanTarget:true})`; mergeFromBase -> `checkoutMergeFromBase(cwd,{baseRef, requireCleanTarget:true})`; discardChanges -> `checkoutDiscardChanges(cwd,{paths})` (error if `!payload.success`); PR ones -> `checkoutPrCreate(cwd,{})`, `checkoutPrMerge(cwd,{method})`, `checkoutForgeSetAutoMerge` vs legacy `checkoutGithubSetAutoMerge` chosen by `features.checkoutForgeSetAutoMerge` / `features.checkoutGithubSetAutoMerge` (else throws "Update the host to use auto-merge actions."). Every client method returns a payload with `error`; the store converts `payload.error.message` into a thrown Error. Squash merge from UI is never used (strategy always "merge"; the protocol supports "squash").
- Archive action (`archive-workspace`): `useWorkspaceArchive` -> for `workspaceKind === "worktree"` first `confirmRiskyWorktreeArchive` (A/git/worktree-archive-warning.ts): reasons = uncommitted changes (isDirty===true, or isDirty unknown with a non-zero diffStat; text with "+N added lines, M deleted lines" when diffStat) and `aheadOfOrigin>0` -> "N unpushed commit(s)"; when no reasons it proceeds silently; else `confirmDialog({title:'Archive "<name>"?', message: reasons.join("\n"), confirm "Archive", cancel "Cancel", destructive:true})`. Risk inputs: `status.isDirty ?? workspace.gitRuntime.isDirty`, `status.aheadOfOrigin ?? workspace.gitRuntime.aheadOfOrigin`, workspace `diffStat`; Archive is disabled for worktrees until both are known. Then `archiveWorkspaceOptimistically` (workspace slice) and redirects away from the active workspace.

## Diff document (A/git/diff-document, shared by working diff, commit diff)
`DiffDocument` props (types.ts): `files: ParsedDiffFile[]`, `contentInsetBottom?`, `displayPreferences {layout:"unified"|"split", wrapLines, codeFontSize, monoFontFamily}`, and either `mode: WorkingDiffMode` (`kind:"working"`, reviewActions, onFilePress, focusPath, focusRequestId, workspaceFileDragScope, onOpenFile/onOpenToSide/onAddToChat/onCopyPath/onCopyRelativePath/onReveal(+revealTargetName)/onDownload/onDuplicate/onRevert) + `collapseState {paths, onChange}`, or `mode: {kind:"commit"}` (no collapse persistence, no file actions). `index.tsx` wraps `DiffSurface` with a themed palette (`createDiffPalette(theme)`, retained across renders) and header typography `{family: theme.fontFamily.ui, size: fontSize.base, statSize: fontSize.sm}`, owns `selectedPath` and `toggleFile` (collapse set <-> persisted `collapsedFilePaths` array).
- Model (model.ts `buildDiffDocumentModel`): a flat virtualized document: per file a section `{top, headerHeight: FILE_HEADER_HEIGHT=30, bodyTop, bodyHeight, bottom, gutterWidth, contentWidth, rowStart,rowEnd,isCollapsed}`; rows are `line` rows (`cells`: 1 cell unified, 2 cells split; cell types add/remove/context/header/empty; `lineNumber`, `tokens: DiffTokenRun[] {start,end,color}` from server highlight tokens via palette.syntax, `fragments` (wrapped visual lines with graphemes/widths), `reviewTarget`, `sourceIdentity {hunkIndex,lineIndex,side}`; `reviewHeight` extra height for inline review comments) or `status` rows (binary / too_large: label `workspace.git.diff.binaryFile` / `workspace.git.diff.tooLarge`, height = lineHeight + 24). `DIFF_BODY_BORDER_HEIGHT = 1`, code padding 16 (`CODE_HORIZONTAL_PADDING`), left padding 8, tab size 4. Collapsed files only emit header. Split layout built from `utils/diff-layout.ts` (`SplitDiffDisplayLine`). Rows are lazily "materialized" (measured/wrapped) only inside a window around the viewport (`materializationWindow`) plus the scroll anchor; unmaterialized rows use estimated heights. Model reuse: `reuseFrom` previous models keyed by identical `ParsedDiffFile` object identity (hence `shareCheckoutDiff`).
- Scroll anchoring (`captureScrollAnchor` / `resolveScrollAnchor` / `resolveRelayoutScrollTop` / `shouldApplyRelayoutScroll`): anchors on a file header (+viewport delta) or a text position so relayout (resize, wrap toggle, new snapshot) keeps the same content in view.
- `createDiffDocumentWorkspaceCache` (workspace-cache.tsx): per-workspace cache `MAX_MODEL_VARIANTS = 4` model variants (key = layout/wrap/viewport/typography/collapsed set) and `MAX_TYPOGRAPHY_RESOURCES = 4` text-measurement resources (LRU).
- Web surface (surface.web.tsx, 1191 lines): one scrolling DOM container with a single `<canvas>` window positioned at the current scroll offset (repainted via requestAnimationFrame; pixel shifting reuse `shiftCanvasPixels` when only scrolling), two pooled sticky header canvases (`git-diff-sticky-header-0/1`, files alternate slots by `fileIndex % 2`), `DomOverlayScrollbar`, `ResizeObserver` with `RESIZE_SETTLE_DELAY_MS = 120`, canvas text measurement `createWebTextMeasurer` (ligature candidates, shaped-run limit 64), mono stack default `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`; own text selection model (`DiffSelection {anchor, focus: DiffCharacterPosition{fileIndex,rowIndex,cellIndex,side,sourceOffset}}`) with hit-testing (`hit-testing.ts`), horizontal scrolling when not wrapping (per-file offsets `horizontal-offsets.ts`), copy handler (`copyToClipboard`, toasts `common.states.copied` / `common.errors.unableToCopy`), context menu `diff-source-context-menu` with `diff-source-copy-selection`, `diff-source-copy-line`, `diff-source-select-all`; hover "+" inline review button (`InlineReviewAddButton`) on reviewable lines; focus request handling: `focusPath` + `focusRequestId` (request key `"<id|initial>:<path>"`) expands a collapsed file and scrolls it to top once per key.
- Native surface (surface.native.tsx 689 lines): `@shopify/react-native-skia` canvas slabs (`native-slabs.ts`: per-file slabs of height `max(768, viewportHeight)`; visible slabs = those intersecting `[scrollTop - vh/2, scrollTop + 1.5*vh]`; window bucket = `floor(scrollTop / max(1, vh/2))`), Reanimated animated ScrollView, `NativeCanvasFileHeader` (Skia header + RN `FileHeader` with `canvasRendered`), touch handlers for taps/long-press, `paint.native.ts` pictures per slab (`SYSTEM_MONO = "monospace"`), `native-text-runs.ts`.
- Inline review: reviewActions (A/review, other slice) add comment editors inline (`reviewHeight` rows) targeting `ReviewableDiffTarget` (utils/diff-layout.ts); in commit mode there are none.
